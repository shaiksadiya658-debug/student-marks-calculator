# Student Marks Calculator

A simple beginner-friendly web project that calculates a student's total marks, percentage, grade, and pass/fail status.

## Features

- Enter student name and roll number
- Enter marks for five subjects
- Calculate total marks out of 500
- Calculate percentage
- Display a grade
- Show PASS or FAIL status
- Responsive layout for desktop and mobile

## Grade rules

- A+: 90% and above
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: Below 50% (if all subjects are passed)
- F: FAIL if any subject mark is below 35

Each subject is marked out of 100. These grading rules are sample rules and can be changed to match your school or college.

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student's details and marks.
4. Click **Calculate Result**.

No installation is required.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — marks and grade calculations
